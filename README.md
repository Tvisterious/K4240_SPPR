# СППР для выбора места путешествия

MVP-прототип системы поддержки принятия решений, объединяющий методы многокритериального анализа, машинного обучения и экспертные системы.

## Возможности
* Рекомендации: Формирование Топ-3 направлений на основе профиля пользователя с текстовым обоснованием.
* База знаний: Автоматическое отсеивание неподходящих вариантов (сезонность, наличие детей, транспортная доступность, бюджет).
* ML-прогноз: Оценка будущей стоимости авиабилетов с помощью Random Forest.
* Управление альтернативами: Добавление и удаление городов через веб-интерфейс.
* Кастомные данные: Загрузка пользовательского CSV-датасета и переобучение модели «на лету».
* BI-аналитика: Просмотр графиков сезонности и распределения цен.

## Стек технологий
* Python 3.10+
* FastAPI, Jinja2, Uvicorn
* Scikit-learn, Pandas, NumPy
* Matplotlib, Seaborn
* Docker

## Запуск через Docker

Сборка образа:
docker build -t travel-sppr .

Запуск контейнера:
docker run -d -p 8000:8000 --name sppr travel-sppr

Приложение будет доступно по адресу: http://localhost:8000

## Локальный запуск

Создание виртуального окружения:
python -m venv venv
source venv/bin/activate  (Для Windows: venv\Scripts\activate)

Установка зависимостей:
pip install -r requirements.txt

Запуск сервера:
uvicorn main:app --host 0.0.0.0 --port 8000 --reload

## Документация API
После запуска интерактивная документация Swagger UI доступна по адресу: http://localhost:8000/docs
